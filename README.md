# B DATA 412 — Advanced Data Visualization

**University of Washington · Autumn 2026 · 5 Credits (RSN)**

Provides advanced training on visualization methods to show data in complex and compelling ways. Applies complex visualization methods to examine topics including project management, the grammar of graphics, data types, data structure, modeling, complex and interactive data visualization, and data dashboards.

**Prerequisites:** B DATA 200 and B DATA 232
